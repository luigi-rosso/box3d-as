# box3d-as

Box3D, Erin Catto's 3D physics engine, ported to AnimaScript as a Rive
scripting library.

Upstream: https://github.com/erincatto/box3d at
`f36d061ba26998c87cb7dc593a4065aaa03fb7eb`. Box3D is MIT licensed; the port
keeps that licence and its attribution, see `LICENSE`.

Work in progress. `CONVENTIONS.md` describes how the C maps to AnimaScript.
